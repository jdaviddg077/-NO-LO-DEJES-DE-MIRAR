# -NO-LO-DEJES-DE-MIRAR
This game is a personal challenge that I will continue working on throughout the coming week until it is finished. I have created all the levels myself, and the lighting is exceptionally well executed; however, to appreciate every detail, you will need to set the graphics to their maximum level (the game is optimized for this). My own PC is not very powerful—in fact, it is a low-end machine—yet it still runs at 60 fps with the settings at maximum, which is incredible. For this project, I have made a special effort to include a more robust narrative, and I have followed your advice to add a README file in English. (I should clarify that this translation was produced using a translation tool; I do not typically use AI for translation, as I feel it fails to convey the message I intend to communicate.)
